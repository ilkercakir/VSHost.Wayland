# VSHost
Virtual Studio Host

Uses hardware audio inputs through ALSA, or PulseAudio sound subsystem or multimedia files as the audio source and implements an audio processing environment. The processed audio frames are output to hardware audio outputs or PulseAudio sound subsystem. Bluetooth connections are supported via PulseAudio. Pipewire suupport has been added. Uses OpenGL ES on Wayland to display video from media file sources. Audio effects processors can be developed and dynamically added. FFMpeg librar,es are used for decoding of multimedia files when used as inputs. The sound output can be recorded to a file.
